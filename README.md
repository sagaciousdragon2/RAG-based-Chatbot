# AI Database Assistant

This project is a Chatbot that retrieves information from a local MongoDB database.

## Project Status
- **Backend**: Python FastAPI (Running on port 8000)
- **Frontend**: React + Vite (Running on port 5173/5174)
- **Database**: MongoDB (Local instance)
- **AI Mode**: Keyword Search (Regex) - *No API Key required*

## How to Run locally

1. **Start Backend**:
   - Open terminal in this folder.
   - Run: `cd backend`
   - Run: `python -m uvicorn main:app --reload`

2. **Start Frontend**:
   - Open a NEW terminal in this folder.
   - Run: `cd frontend`
   - Run: `npm run dev`

3. **Open App**:
   - Go to `http://localhost:5173` (or the port shown in terminal).
